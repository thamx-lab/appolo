# OG Image Instructions

Place your social share image here as: `og-image.jpg`

## Requirements:
- Size: exactly 1200 x 630 pixels
- Format: JPG
- File name: og-image.jpg
- Content: Your gym logo + "Black Sheep Sanctuary" text on a dark background

## How to create one (free):
1. Go to https://www.canva.com
2. Click "Create a design" → type "1200x630" → custom size
3. Design your card with the Black Sheep logo, gym name, and tagline
4. Download as JPG
5. Place the file here: frontend/public/og-image.jpg

This image shows when someone shares your website link on WhatsApp, Facebook, Twitter, etc.
